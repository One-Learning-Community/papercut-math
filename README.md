# quoin/math has moved to Phactorial

This package is now [Phactorial](https://github.com/One-Learning-Community/phactorial), published as
`phactorial/phactorial`. Releases through 0.17.0 stay installable here, but nothing new will be published as
`quoin/math`.

To move:

- In `composer.json`, replace `quoin/math` with `phactorial/phactorial` (`^0.18`).
- Rename `Quoin\Math\…` to `Phactorial\…`, for example `Quoin\Math\Math` to `Phactorial\Math`.

Documentation lives at https://one-learning-community.github.io/phactorial/, and issues and pull requests go to
[One-Learning-Community/phactorial](https://github.com/One-Learning-Community/phactorial).
